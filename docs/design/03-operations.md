# 操作方法

## 起動

プロジェクト直下で実行します。

```bash
docker compose up --build -d
```

ブラウザで以下を開きます。

```text
http://localhost:3000
```

APIは以下で起動します。

```text
http://localhost:8000
```

## 停止

```bash
docker compose down
```

## 表示が古い場合

画面右上の `Reset` を押すと、選択中の職人、料理名、使用道具、道具の★数を維持したまま、数値と配置を選択中レシピの初期状態へ戻します。

現在値、基準値、成功範囲、配置、特性状態などをレシピ読み込み直後の状態に戻したい場合に使用します。

## 基本操作

1. 職人種別を選びます。
2. 制作物を選びます。
3. 職人レベルを選びます。
4. 使用道具と道具の★数を選びます。
5. 自動計算された集中力を確認します。
6. 温度、ぬいパワー、火力状態などを選びます。
7. 各マスの現在値、基準値、成功下限、成功上限を入力します。
8. 盤面、表の判定、候補手を確認します。

## 表示項目

| 項目 | 意味 |
| --- | --- |
| 現在値 | 現在の焼け具合や進行値 |
| 光 | レシピ特性が光の場合に、調理の具材が光っているかどうか |
| 光・戻り | レシピ特性が光・戻りの場合に、上下左右が光るか四隅が戻るか |
| 種別 | 調理の位置、木工の木目など、職人固有の入力種別 |
| 基準値 | 会心発生時に到達したら止まる誤差0の値 |
| 成功下限 | 成功範囲の下限 |
| 成功上限 | 成功範囲の上限 |
| 基準まで | 基準値との差 |
| 下限まで | 成功下限との差 |
| 上限まで | 成功上限との差 |
| 通常後 | 各特技を通常成功した場合の想定範囲 |
| 会心後 | 各特技で会心が出た場合の想定範囲 |
| 判定 | 本会心固定、固定、会心時確定、通常時超過の可能性あり、不足、超過中、偽会心の可能性あり |

## 盤面表示

盤面は、職人ごとの最大サイズでマスを表示します。

| 職人 | 表示 |
| --- | --- |
| 鍛冶系 | 横2×縦4の範囲に、使用マスだけを配置 |
| 裁縫 | 横3×縦3の範囲に、使用マスだけを配置 |
| 調理 | 横3×縦3固定で、場所に応じて中央、上下左右、四隅を表示 |
| 木工 | 横3×縦3固定で、マスごとの並行、垂直を表示 |

調理以外では、盤面のマスをクリックすると、一覧表の該当マスの現在値入力へ移動します。

調理では、盤面クリックでフライパン配置を入れ替えます。
具材を1つ選択すると、同じ `ingredientGroupId` の具材も同時に選択表示されます。

調理の配置操作:

1. 具材マスをクリックして選択します。
2. 移動先の具材または空白マスをクリックします。
3. `戻る`、`進む` で配置変更をUndo/Redoできます。

BOARDの共通操作には、調理固有の操作ボタンを表示しません。
調理固有の必殺、火力、特性操作は、フライパン配置内の調理専用コマンド領域に表示します。
調理では、必殺内の `ミラクルグリル` の文字を左クリックすると必殺表示を `未チャージ`、`チャージ済み`、`使用済み` の順に切り替えます。

複数マス食材は、横2マスまたは縦2マスの形を保って移動します。
調理で2マス食材として扱うのは、肉と魚の切り身だけです。
3マス以上が同じ `ingredientGroupId` になっている場合は結合食材として扱いません。
隣が1マス食材の場合は、複数マス食材が空けた端のマスへ相手を移して交換します。
移動先が空白のみ、または1マス食材と空白の組み合わせでも移動できます。
ただし、移動先に別の複数マス食材の一部だけが含まれる場合は、相手食材の形が崩れるため交換しません。
例として、テンキー配置の `2,3` が同一食材、`4,5` が別の同一食材、`6` が1マス食材の場合、`2,3` を上へ動かす操作は失敗します。

調理のフライパン配置では、マスを右クリックすると現在値、固定状態、特性状態を直接編集できます。
固定状態は現在値が基準下限から基準上限までの範囲内にある場合だけ指定できます。
右クリック編集は、`更新` を押すか編集枠の外側を押すと入力内容を反映します。
`閉じる` または `Esc` では入力内容を反映せず閉じます。

レシピ特性が `光` の場合は、対象マスが光っているかを個別に変更できます。

レシピ特性が `光・戻り` の場合は、`上下左右が光る` または `四隅が戻り` を選択できます。

成功範囲や基準値などの詳細編集は一覧表で行います。

## 制作物

制作物を選ぶと、マス名、配置、基準値、成功範囲をまとめて読み込みます。

道具鍛冶では、基本設定に大項目と道具名を表示します。
大項目は `refarence/tool` の8種類に合わせて、ツボ、ハンマー、フライパン、ランプ、ルアー、木工刀、素材、針を表示します。
道具名は具体的な制作物名です。選択した大項目に登録済みの道具名がない場合は、選択欄を無効化して `未登録` と表示します。

料理データはAPIから取得します。

APIが利用できない場合は、フロント内のフォールバックデータを使用します。

現在値だけを変更した場合、選択中のレシピは維持します。

成功範囲やマス名を変更した場合は、手入力扱いになります。
ただし、調理職人はレシピ数が少なくプリセット運用を前提にするため、レシピ選択欄に「手入力」は表示しません。

調理レシピの特性は `光`、`光・戻り`、`回復` の3種類です。
現時点では特性を表示・保存しますが、4ターンごとの効果は計算へ反映していません。

調理の `強火焼き` と `弱火焼き` は4ターン継続する火力状態として扱います。
盤面上部の火力切替ボタンで `通常`、`強火焼き`、`弱火焼き` を切り替え、基本設定の火力状態と同期します。
火力状態を切り替えると、一覧、盤面セル、調理メモ、集計の判定表示を同じ条件で再計算します。

## 判定ラベル

| ラベル | 意味 |
| --- | --- |
| 本会心固定 | 通常ダメージ候補の2倍では表せない固定状態 |
| 固定 | ミラクルグリル成功などで理想値に固定された状態 |
| 会心時確定 | 現在値が基準下限未満で、会心最小値でも基準下限に届く状態 |
| 通常時超過の可能性あり | 通常最大値を加えると基準上限を超える可能性がある状態 |
| 不足 | 会心最大値でも基準下限に届かない状態 |
| 超過中 | 現在値がすでに基準範囲の最大を超えている状態 |
| 偽会心の可能性あり | 会心最大値なら基準下限へ届くが会心最小値では届かない状態 |
| 基準内 | 現在値が基準範囲内で、通常最大値でも基準上限を超えない状態 |

## 特技データ

特技ごとの固定値を確認できます。

- 消費集中
- 通常範囲
- 会心範囲
- 威力倍率

調理職人では、通常の焼き、弱火焼き、強火焼き、ねらい焼きを特技データとして表示しません。
通常・会心範囲は現在火力、現在位置、光状態から算出し、特技データには必殺のミラクルグリル、半熟封じ、完熟封じ、焼き戻しを表示します。
調理の判定は、現在値、基準下限、基準上限と、現在火力・現在位置から引いた位置別ダメージの最小値、最大値を比較します。

調理の `ミラクルグリル` は調理専用コマンドの必殺として表示し、通常範囲ではなく理想値到達の専用処理を使います。
必殺表示が `使用済み` の場合は、選択中の食材を通常より強調して表示します。
通常後・会心後の範囲比較や代表判定には含めず、使用時だけ専用処理として適用します。
ミラクルグリル成功後は、固定時の増加量から本会心固定か偽会心の可能性ありかを判定します。
`半熟封じ` は食材1マスの焼きダメージを半減し、小数点以下を繰り上げます。
`完熟封じ` は食材1マスのダメージと回復を無効化します。
`焼き戻し` はマス位置に作用し、食材が移動しても対象位置を焼かずに回復します。
画面上の表示分類は、固定、本会心固定、会心時確定、通常時超過の可能性あり、不足、超過中、偽会心の可能性あり、基準内を扱います。

画面上では特技ダメージを編集しません。

会心発生時に基準値へ届く場合は、基準値で止まるものとして判定します。

そのため、会心後の表示は上限超過ではなく誤差0の値になる場合があります。

調理は具材位置、木工はマスごとの木目、裁縫はぬいパワーによって特技範囲が変わります。
鍛冶系は温度ごとの数値範囲を設定ファイルで管理します。
火力状態で温度を選ぶと、選択温度に応じた特技範囲が表示されます。
鍛冶系のBOARDでは、鍛冶配置の下に現在温度の威力別ダメージ表を表示します。
会心時は通常ダメージの2倍として扱い、ダメージ表には最大ダメージの下に会心時の最低ダメージを表示します。
温度別ダメージの下には、JSON登録した鍛冶特技の消費集中、特技名、倍率、範囲を表示します。
この温度はBOARD内の `-50℃`、`+50℃` 操作で変更でき、基本設定の温度選択と同期します。
鍛冶配置のマスを右クリックすると、現在値を変更しながら、現在温度の各倍率で打った場合の判定を確認できます。
特性が `光地金` の場合は、温度が200の倍数の時だけマスごとの光状態を選択できます。`倍半`、`戻り`、`集中変化` は温度条件で自動反映し、手動の光状態指定は使いません。

調理は具材ごとの位置種別、裁縫はぬいパワー、木工は各マスの木目を選ぶと、選択状態に応じた特技範囲が表示されます。
木工では順目を並行、逆目を垂直として扱います。

数値を変更する場合は、対象職人の `app/crafts/<職人>/config.js` を編集します。
鍛冶特技表に表示する一覧は `app/crafts/shared/smithing-techniques.json` を編集します。

## 集中力

集中力は画面上で直接編集しません。

職人レベル、使用道具、道具の★数から自動計算します。

実際のレベル別集中力と道具補正は、対象職人の `app/crafts/<職人>/config.js` にある `focus` 設定で管理します。

鍛冶ハンマーとフライパンの★は会心率に影響し、集中力は道具種類の集中度で増減します。
そのため、★を変えても集中力が変わらない道具があります。
奇跡の鍛冶ハンマーと奇跡のフライパンは、集中力 +50 として扱います。
光の鍛冶ハンマーは、鍛冶職人共通で集中力 +45 として扱います。

鍛冶の Lv80 集中力は 208 として扱います。
鍛冶の Lv76-79 と調理の Lv76-80 集中力は、暫定的に Lv75 以降を各レベル +2 として扱います。

鍛冶職人と調理職人では、基準下限と基準上限の間から実際の基準値がランダムに決まるものとして判定します。

## マス構成の扱い

マス構成は、選択中のレシピまたはレシピリストから追加した内容を使います。
レシピ追加ウィンドウではマスを追加・削除できます。

現在値や固定状態など、作業中に変わる値はBOARD上のセル編集で更新します。

## 設定の保存

入力内容はブラウザの `localStorage` に自動保存されます。

同じブラウザで再度開くと、前回の状態が復元されます。

## レシピリスト

1. 画面上部の `レシピリスト` ボタンを押します。
2. `職人を選択` で対象職人を選びます。
3. 大項目を持つ職人では、対象の大項目を展開します。
4. レシピ名を左クリックすると、そのレシピの編集ウィンドウを開きます。

削除を押すと、対象レシピは通常のレシピ選択とレシピリストから除外されます。
調理職人では大項目を表示せず、レシピ名、特性、各基準範囲を直接編集します。
木工、裁縫、鍛冶系では大項目を持つ場合、従来どおり大項目別に表示します。

## レシピ編集

1. `レシピリスト` を開きます。
2. 対象レシピ名を左クリックします。
3. 名称、特性、大項目、各マスの名称、位置、基準値、下限、上限を修正します。
4. `保存` を押します。

API由来のレシピを編集した場合も、変更内容はブラウザのユーザーレシピとして同じIDで保存し、画面上では編集済み内容を優先して表示します。

## レシピ追加

1. `レシピリスト` を開きます。
2. 対象職人と、必要に応じて大項目を選びます。
3. 一覧下部の `新規追加` を押します。
4. レシピ名、特性、マスごとの基準値と成功範囲を入力します。
5. `追加` を押します。

入力項目は職人設定に従って変わります。

- 大項目を持つ職人では大項目を選択します。
- 道具鍛冶では大項目ごとに、`refarence/tool` の参照画像に合わせたマス数で初期表示します。
- 特性を持つ調理職人では特性を選択します。
- 位置や食材分類など、職人固有の項目がある場合はマス設定に表示します。

追加・削除したレシピはブラウザの `localStorage` に保存されます。
