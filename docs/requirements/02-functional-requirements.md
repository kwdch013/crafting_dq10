# 機能要件

## 職人種別選択

ユーザーはUI上で現在プレイ中の職人を選択できます。

初期対応:

- 調理職人

設定ファイル準備済み:

- 武器鍛冶
- 防具鍛冶
- 道具鍛冶
- 裁縫
- 木工

## DQ10ウィンドウ選択

将来的に、起動中のウィンドウ一覧からDQ10のウィンドウを選択できるようにします。

要件:

- 対象ウィンドウを選択できる
- ウィンドウサイズ変更に対応する
- ウィンドウ位置変更に対応する
- 必要に応じて再キャリブレーションできる

## キャプチャ機能

DQ10画面を一定間隔でキャプチャします。

ブラウザ版の初期実装:

- 画面共有APIでユーザーが選択した画面またはウィンドウをプレビューする
- 取得元名、解像度、接続状態を表示する
- 任意のタイミングで現在フレームをcanvasへ転写する
- 転写したフレームは後続のOCRや画像処理の入力として扱う

初期目標:

- 1秒あたり2から5回程度の更新

将来目標:

- 必要に応じて10fps程度まで対応

要件:

- 対象ウィンドウのみをキャプチャする
- 解析対象領域のみを切り出す
- CPU負荷を抑える
- GPUなし環境でも動作する

## キャリブレーション

画面サイズ変更に対応するため、職人UI領域の位置を調整できるようにします。

方式:

- 自動検出
- 手動範囲指定
- ウィンドウサイズ比率による補正

MVPでは手動範囲指定を許容します。

## 調理職人の状態管理

初期段階では、レシピ選択、レシピリストからの追加・削除、BOARD上のセル編集で状態を指定できるようにします。

入力項目:

- 制作物
- 道具鍛冶の大項目と小項目
- 各具材の現在焼け具合
- レシピ特性
- レシピ特性が光の場合の各具材の光状態
- レシピ特性が光・戻りの場合の上下左右の光、または四隅の戻り状態
- 各具材の成功範囲
- 現在の集中力
- 火力状態
- 選択可能な特技
- 使用中の効果

## 調理職人の画面認識

画面認識対応後は、以下の情報を読み取ります。

- 具材位置
- 各具材のゲージ状態
- 集中力
- コマンド選択状態
- フライパン上の火力位置
- 光っている具材
- 戻り対象の具材
- 特技使用状態
- 会心、光、光・戻り、回復などの判定に必要な表示

認識方式:

- 数値: OCR
- ゲージ: 色判定、位置判定、テンプレート照合
- 具材位置: テンプレート照合または固定レイアウト補正
- コマンド: OCRまたはテンプレート照合

## 数値表示

UIには以下を表示します。

- 各マスの現在値
- 成功下限との差
- 成功上限との差
- 各特技の通常行動時の想定ダメージ範囲
- 各特技の会心時の想定ダメージ範囲
- 安全、狙い目、危険、超過の状態

## 確定会心判定

各マスについて、会心が発生した場合に成功範囲へ確定で入るかを判定します。

会心時は威力を2倍で計算し、基準値を超える場合はそれ以上増えず、基準値ちょうどで停止します。

そのため、確定会心判定は会心停止を反映した後の値で行います。
調理職人では、現在火力と具材位置から位置別ダメージ範囲を参照し、現在値に会心最小値を加えた値が基準下限へ届く場合を会心時確定とします。

```text
会心停止後の最小値 >= 成功下限
かつ
会心停止後の最大値 <= 成功上限
の場合、確定会心候補
```

会心停止が発生しないまま成功上限を超える場合は、超過リスクとして表示します。

## おすすめ手提示

現在状態から次に選ぶべき候補手を提示します。

候補手評価項目:

- 成功範囲へ入る確率
- 会心発生時の有利度
- 超過リスク
- 次ターン以降の自由度
- 消費集中力
- 残り集中力との相性
- 特技の効果

## 設定保存

以下の設定を保存できるようにします。

- 対象ウィンドウ
- 職人種別
- キャプチャ間隔
- キャリブレーション情報
- 表示項目
- 職人ごとの成功範囲データ
