# 概要とスコープ

## 目的

本ツールは、PC版「ドラゴンクエストX」の職人ミニゲームを補助するためのツールです。

職人作業中の状態を数値化し、成功範囲との差分、会心時の判定、超過リスク、候補手を見やすく表示します。

## 基本方針

- 初期対応は調理職人です。
- 将来的に鍛冶、裁縫、木工、ランプ錬金、ツボ錬金へ拡張します。
- GPUは必須にしません。
- Local LLMは中核機能に使用しません。
- 画面全体をAIで解析せず、必要な領域だけを扱います。
- 数値計算とおすすめ手の判定はルールベースで実装します。

## 開発環境

- メインPC
- CPU: Intel Core Ultra 265KF
- GPU: NVIDIA RTX 5070 Ti
- 解像度: 1920 x 1080
- DQ10: PC版

## 動作目標環境

- サーバー用PCでも動作可能にします。
- CPU: Intel Core i7 第8世代程度
- GPU: なし
- メモリ: 16GB推奨、8GBでも軽量動作を目指します。

## MVPスコープ

初期バージョンでは調理職人を中心に以下を実装します。

- 職人種別の選択
- 調理職人モードの選択
- 別ウィンドウ相当の補助表示
- 現在の焼け具合の手入力
- 各具材の成功範囲との差分表示
- 各マスの通常ダメージ範囲表示
- 各マスの会心時判定表示
- 確定会心候補の表示
- 危険マス、超過リスクの表示

## 将来スコープ

- 画面キャプチャからの自動認識
- DQ10ウィンドウ選択
- 手動キャリブレーション
- OCRと画像処理による値の読み取り
- おすすめ手の自動提示
- 全職人への対応
- 職人ごとの計算エンジン追加
- 設定プリセット保存
- 解析ログ保存
- 成功率、期待値、リスク評価の高度化

## スコープ外

- ゲーム操作の自動化
- DQ10プロセスのメモリ読み取り
- マクロ操作
- 外部サーバーへの画面送信
- LLMによる数値判定

## 安全方針

本ツールは、ユーザーが画面を見て判断するための補助表示に限定します。

ゲームへの入力、プロセス内部の読み取り、外部送信は行いません。
