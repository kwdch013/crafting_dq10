# GitHub Issues

## 目的

現状の問題点と残タスクをGitHub issueで管理します。

リポジトリ:

```text
https://github.com/kwdch013/crafting_dq10
```

## ラベル運用

issueには対象領域に応じてラベルを付与します。

- `調理職人`
- `武器鍛冶`
- `防具鍛冶`
- `道具鍛冶`
- `裁縫`
- `木工`
- `共通`
- `その他`

複数職人にまたがる基盤、API、ドキュメント、テストは `共通` を使います。
