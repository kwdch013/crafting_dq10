# 裁縫職人仕様

裁縫職人に固有のぬいパワー操作と判定表示の仕様メモです。

## ぬいパワー操作

裁縫職人の選択時は、BOARD上部に次の切替ボタンを表示します。

- 弱い
- 普通
- 強い
- 最強
- 会心×2

候補のIDとラベルは `app/crafts/shared/sewing-damage.js` の
`DQ10SewingDamage.powerStates` を正とします。

BOARD上部で選んだぬいパワーは、基本設定のぬいパワープルダウンと同期します。
基本設定側で変更した場合も、選択中のBOARDボタンを `active` 表示へ更新します。
ぬいパワーの変更では操作領域を折りたたまないため、ボタンやBOARDの位置は動きません。

## 再生布

再生布はぬいパワーではなく布の性質として扱います。
裁縫職人の選択時は、BOARD上部のぬいパワーボタン群の隣に「再生布」トグルを表示します。
押すたびにON/OFFが切り替わり、ON時はボタンを `active` 表示にして `aria-pressed="true"` とします。
状態は `state.sewingRegenerateCloth` に保存し、再読込時に復元します。

旧版でぬいパワーが `regenerate` の状態を読み込んだ場合は、ぬいパワーを普通 (`normal`) に移行し、再生布をONにします。

## 判定への反映

ぬいパワーを切り替えると、特技データ、BOARD、右クリック判定、ANALYSISを再描画します。
右クリック判定を開いている場合も、入力中の現在値を保ったまま新しいぬいパワーで再計算します。

ダメージ候補と参考確率は `DQ10SewingDamage.getDistribution(powerId, actionId)` で取得し、実データは `distributions` に保持します (会心×2 は参照時に普通へ読み替えるため `distributions` には定義しません)。
会心×2のダメージ候補と参考確率は普通と同一で、会心率のみ2倍として扱います。
会心時に基準値へ届く場合は、基準値を超過せず停止します。

再生布ON時は、右クリック判定の末尾に「再生」行を表示します。
回復量は -12〜-16で、各値の発生率は20%です。通常の特技行は再生布のON/OFFに関係なく、選択中のぬいパワーで解決します。
再生布OFF時は「再生」行を表示しません。トグル自体は常に同じ位置へ表示するため、ON/OFFでBOARDやボタンの位置は動きません。

ターン経過による回復の自動適用は行いません。

## 他職人との分離

ぬいパワー操作は裁縫職人でのみ表示します。
鍛冶3職人、調理職人、木工職人では裁縫専用操作を表示しません。
