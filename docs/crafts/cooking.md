## 会心ダメージ

会心が出たとき、そのダメージは基本的に、その具材があるマスで出る通常ダメージの2倍になります。

判定順序は、会心時の威力を2倍で計算し、その結果が理想値を超える場合に理想値で停止する流れです。

例:

- 四隅の通常ダメージが `3 / 4 / 5`
- 会心ダメージは `6 / 8 / 10`

そのため、会心で出る最大ダメージは、そのマスで出る可能性がある通常ダメージ最大値の2倍までです。

## 会心停止

会心ダメージが理想値を超える場合、焼き具合はそれ以上増えず、理想値ちょうどで止まります。

このとき、その具材は理想値との誤差が `0` になり、ゲージが固定されます。

判定上の意味:

- 会心ダメージが奇数として観測された場合、通常ダメージの2倍では表せないため、理想値で止まった本会心と見なせます。
- そのマスの通常ダメージ最小値の2倍より小さい会心ダメージが観測された場合も、理想値で止まった本会心と見なせます。
- 会心で固定されたときに、観測ダメージがそのマスの通常ダメージ候補の2倍と一致する場合は、偽会心の可能性があります。

## 会心固定

会心が出たときにダメージが2ゲージ目に届く、または2ゲージ目の間で会心が出た場合、その具材は固定されます。

固定された具材には、それ以上ダメージが入りません。

例外:

- `混ぜ合わせ` を使うと、固定状態を解除できます。

今後の実装では、食材ごとに固定状態を保持する必要があります。

候補フィールド:

```json
{
  "locked": true
}
```

## 超過中の会心

現在の焼き具合が理想値を超えている場合、会心の焼き具合は出ません。

理想値を超えた状態で `ミラクルグリル` を使うと、miss扱いになります。

## ミラクルグリル

`ミラクルグリル` は調理職人の必殺です。

職人中に確率で一回発動でき、対象食材が理想値を超過していなければ、確定で会心扱いになり、基準値ちょうどになります。

画面ではフライパン配置の食材を選択してから `ミラクルグリル` を押します。
成功または miss の結果は配置操作欄に表示し、一度使うと使用済みとしてボタンを無効化します。
肉または魚の2マス食材を選択した場合は、同じ `ingredientGroupId` の両マスへ同時に適用します。

実装時の判定:

| 状態 | 結果 |
| --- | --- |
| 現在値が理想値以下 | 基準値ちょうど、誤差0、固定 |
| 現在値が理想値超過 | miss |

成功時は食材に `locked: true` を設定し、以後の判定表示では通常後・会心後を現在値のまま表示します。
現在値を手入力で変更した場合は、補正入力として固定状態を解除します。

固定された場合は、基準値までの増加量をその位置・火力の通常ダメージ候補の2倍と比較します。
増加量が通常ダメージ候補の2倍と一致する場合は `偽会心の可能性あり`、一致しない場合は `本会心固定` と表示します。
増加量が奇数、または通常ダメージ候補の2倍では表せない値の場合は、本会心で理想値に止まったものとして扱います。

## 特性

レシピごとに、4ターンに一回発生する特性があります。

現在の分類:

| ID | 表示名 | 内容 |
| --- | --- | --- |
| `light` | 光 | 食材が置いてあるランダムな1マスが光る |
| `light-return` | 光・戻り | 上下左右が光る回と、四隅が戻る回が交互に訪れる |
| `recovery` | 回復 | 基準値外の食材が回復する |

レシピデータでは `traitId` に記録します。
旧データの `none` は `light`、`return` は `recovery` として正規化します。

例:

```json
{
  "name": "バトルステーキ",
  "traitId": "light-return"
}
```

未確認レシピの特性は暫定値が残る可能性があります。
実データ確認は GitHub issue #11 で追跡します。

## 食材サイズ

食材には、1マス食材と複数マス食材があります。

複数マス食材は、同じ食材を構成するマスが同時に動く仕様です。
調理で結合する食材は2マスまでです。
2マス食材として扱う種類は肉と魚の切り身だけです。

現在は肉または魚の切り身で、`ingredientGroupId` が同じマスがちょうど2つある場合だけ同一食材グループとして扱い、フライパン配置の移動、入れ替え、上へずらす操作をまとめて行います。
入れ替えはグループ全体の左上位置を交換するため、横2マスまたは縦2マスの食材はクリックしたマスに関係なく同じ並びのまま動きます。
方向ボタンで入れ替える場合は、隣が1マス食材でも結合食材が空けた端のマスへ移して交換します。
移動先が空白だけの場合や、1マス食材と空白が混在する場合も、結合食材の形を保って上下左右へ移動できます。
移動先に別の複数マス食材の一部だけが含まれる場合は、その食材グループを分断しないため交換しません。
テンキー配置で `2,3` が同一食材、`4,5` が別の同一食材、`6` が1マス食材の場合、`2,3` の上移動は交換不可です。

使用フィールド:

```json
{
  "ingredientGroupId": "meat-1",
  "ingredientGroupLabel": "肉",
  "ingredientSize": 2
}
```

確認済みの画像参照は `refarence/cooking/` に配置します。

現時点で反映済み:

- `バトルステーキ`: 肉2組、野菜2マス、`光・戻り`
- `ヒールカルボナーラ`: 肉、麺3マス、卵、`回復`

`くわしくみる.png` は、今後の画像認識で基準値や状態を読み取る際の参照画像として扱います。

## 食材画像表示

フライパン配置は3x3の長方形グリッドとして表示します。
各マスでは、`ingredientGroupLabel` から食材種別を判定し、DQ10画面の参照画像を表示します。

対応種別:

- `肉`
- `魚の切り身`
- `野菜`
- `麺`
- `卵`

参照画像は `app/assets/cooking/` に配信用として配置します。
元画像は `refarence/cooking/` のスクリーンショットです。
`ingredientGroupLabel` が未入力の場合は、レシピカテゴリだけでは食材種別を断定しません。
カテゴリ単位で推定すると肉料理の全マスが肉画像になるため、画像なしの従来表示に戻します。
配置移動でレシピが手入力扱いになった後も、明示済みの `ingredientGroupLabel` は保持し、対応する画像を継続表示します。

画像はセル内へ収まるように表示し、現在値、判定基準、判定ステータスを同じセル内で確認できるようにします。
魚など縦長の素材画像はセル内の画像領域に収め、隣接画像が混入して見えないように右端を表示側でクリップします。

## 光効果の手動制御

`光` と `光・戻り` は1ターン効果として扱います。
`光` は盤面セル内の光ボタン、各マスのチェック、右クリック編集でオン/オフし、盤面上部の `光を全解除` で全マスをオフにできます。
`光・戻り` は盤面上部または右クリック編集で、`効果なし`、`上下左右が光る`、`四隅が戻り` を切り替えます。
レシピ切替、特性切替、保存状態の読み込みでは `効果なし` から開始し、上下左右が常に光る状態にはしません。
光ボタン、全解除、`光・戻り` の切替は盤面操作のUndo/Redo対象です。

ブラウザ上での方向入れ替え検証は GitHub issue #12 で追跡します。

## ダメージ表

四隅、上下左右、中央、強火焼き、弱火焼き、火力アップターンなどの詳細なダメージ表は、公式ガイドブックの「氷の領海＋職人の極意編」に掲載されている情報を参照対象とします。

光マスの通常ダメージ幅は `24 - 36` です。

弱火焼き、強火焼きでは通常の光マス基準幅へ火力補正をかけます。

| 状態 | 光マス幅 |
| --- | --- |
| 通常 | `24 - 36` |
| 強火焼き | `36 - 54` |
| 弱火焼き | `18 - 27` |

このリポジトリでは、確認済みの値を `app/crafts/shared/cooking-damage.js` に反映します。
