## 会心ダメージ

会心が出たとき、そのダメージは基本的に、その具材があるマスで出る通常ダメージの2倍になります。

判定順序は、会心時の威力を2倍で計算し、その結果が理想値を超える場合に理想値で停止する流れです。

例:

- 四隅の通常ダメージが `3 / 4 / 5`
- 会心ダメージは `6 / 8 / 10`

そのため、会心で出る最大ダメージは、そのマスで出る可能性がある通常ダメージ最大値の2倍までです。

## 会心停止

会心ダメージが理想値を超える場合、焼き具合はそれ以上増えず、理想値ちょうどで止まります。

このとき、その具材は理想値との誤差が `0` になり、ゲージが固定されます。

判定上の意味:

- 会心ダメージが奇数として観測された場合、通常ダメージの2倍では表せないため、理想値で止まった本会心と見なせます。
- そのマスの通常ダメージ最小値の2倍より小さい会心ダメージが観測された場合も、理想値で止まった本会心と見なせます。
- 会心で固定されたときに、観測ダメージがそのマスの通常ダメージ候補の2倍と一致する場合は、偽会心の可能性があります。

## 会心固定

会心が出たときにダメージが2ゲージ目に届く、または2ゲージ目の間で会心が出た場合、その具材は固定されます。

固定された具材には、それ以上ダメージが入りません。

例外:

- `混ぜ合わせ` を使うと、固定状態を解除できます。

今後の実装では、食材ごとに固定状態を保持する必要があります。

候補フィールド:

```json
{
  "locked": true
}
```

## 超過中の会心

現在の焼き具合が理想値を超えている場合、会心の焼き具合は出ません。

理想値を超えた状態で `ミラクルグリル` を使うと、miss扱いになります。

## ミラクルグリル

`ミラクルグリル` は調理職人の必殺です。

職人中に確率で一回発動でき、対象食材が理想値を超過していなければ、確定で会心扱いになり、基準値ちょうどになります。

実装時の判定:

| 状態 | 結果 |
| --- | --- |
| 現在値が理想値以下 | 基準値ちょうど、誤差0、固定 |
| 現在値が理想値超過 | miss |

## 特性

レシピごとに、4ターンに一回発生する特性があります。

現在の分類:

| ID | 表示名 | 内容 |
| --- | --- | --- |
| `none` | 未設定 | 特性が未確認のレシピに使う内部値 |
| `light-return` | 光・戻り | 上下左右が光る回と、四隅が戻る回が交互に訪れる |
| `return` | 戻り | 超過しているもの、または基準値外にあるもののうち、最も値が大きい食材が1つ戻る |
| `light` | 光 | 食材が置いてあるランダムな1マスが光る |
| `double-half` | 倍半 | 威力が倍になる状態と半分になる状態が交互に訪れる |

レシピデータでは `traitId` に記録します。

例:

```json
{
  "name": "バトルステーキ",
  "traitId": "light-return"
}
```

`バトルパッツァ` は `光・戻り` の例として扱いますが、現在のレシピデータには未登録です。追加時は `traitId: "light-return"` を設定します。

## 食材サイズ

食材には、1マス食材と複数マス食材があります。

複数マス食材は、同じ食材を構成するマスが同時に動く仕様です。

現在は `ingredientGroupId` が同じマスを同一食材グループとして扱い、フライパン配置の移動、入れ替え、上へずらす操作をまとめて行います。

使用フィールド:

```json
{
  "ingredientGroupId": "meat-1",
  "ingredientGroupLabel": "肉",
  "ingredientSize": 2
}
```

確認済みの画像参照は `refarence/cooking/` に配置します。

現時点で反映済み:

- `バトルステーキ`: 肉2組、野菜1組、`光・戻り`
- `ヒールカルボナーラ`: 肉、麺、卵、`戻り`

`くわしくみる.png` は、今後の画像認識で基準値や状態を読み取る際の参照画像として扱います。

## ダメージ表

四隅、上下左右、中央、強火焼き、弱火焼き、火力アップターンなどの詳細なダメージ表は、公式ガイドブックの「氷の領海＋職人の極意編」に掲載されている情報を参照対象とします。

光マスの通常ダメージ幅は `24 - 36` です。

弱火焼き、強火焼きでは通常の光マス基準幅へ火力補正をかけます。

| 状態 | 光マス幅 |
| --- | --- |
| 通常 | `24 - 36` |
| 強火焼き | `36 - 54` |
| 弱火焼き | `18 - 27` |

このリポジトリでは、確認済みの値を `app/crafts/shared/cooking-damage.js` に反映します。
