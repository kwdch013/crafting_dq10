# 木工職人仕様

木工職人に固有のダメージ候補、発生率、くさび状態の仕様メモです。

## ダメージ候補

基礎データは `app/crafts/shared/woodworking-damage.js` に置き、
`refarence/woodworking/木工ダメージ.png` の順目、逆目、くさび順目、くさび逆目を正解とします。

画像の各欄に並ぶ値は、それぞれ同じ確率で選ばれる候補です。
同じ値が複数回記載されている場合は、画面表示時に発生率を合算します。
例えば、くさび逆目の通常候補 `10 / 11 / 12 / 13 / 13 / 14 / 15` では、
`13` を `28.6%`、その他の値をそれぞれ `14.3%` と表示します。

## 威力表

通常とくさびの双方で、次の威力キーを個別の候補表として保持します。

| キー | 用途 |
|---|---|
| `plane` | カンナがけ |
| `power_0_8` | 昇竜彫りの上、大昇竜の上 |
| `normal` | けずる、ねらい削り |
| `power_1_1` | 大昇竜の中 |
| `power_1_4` | 昇竜彫りの下、大昇竜の下 |
| `power_2_0` | 2倍削り |
| `power_3_0` | 3倍削り |

2倍削りと3倍削りは、通常削りを複数回抽選した合計ではありません。
参照画像に記載された7候補を直接使います。
会心時は選ばれたダメージを2倍にし、基準値へ届く場合は基準値で停止します。

## くさび操作

BOARDの木工マスを右クリックし、`くさびを使う` をオンまたはオフにして更新します。
切替中は、同じ右クリックメニュー内の威力別ダメージ、発生率、判定へ即時反映します。
更新後はマスごとの `isWedged` として保存し、Undo／Redoの対象に含めます。

BOARD上には `くさびON` または `くさびOFF` を常に表示します。
状態変更でマスの表示領域が増減しないよう、オンとオフで同じバッジ領域を使います。
